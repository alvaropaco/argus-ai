What is ARGUS?

ARGUS is an infrastructure control plane designed to operate heterogeneous systems continuously. Kubernetes is supported, but is not a prerequisite or the definition of the product.

Discover

Understand hosts, kernels, processes, cgroups, namespaces, containers, services, networks, storage, databases, Kubernetes workloads and dependencies.

Reason

Combine observations, telemetry, history, policies and LLM reasoning to form hypotheses and operational plans.

Operate

Execute typed capabilities through a privileged, policy-controlled Rust boundary and verify the resulting state.

Architecture

The runtime separates intelligence from authority. Infrastructure-specific functionality lives behind adapters, capabilities and plugins.

 ├── Agent / Plugin
 └── Event

Linux kernel interfaces are treated as first-class sources of truth. Kubernetes adds a control-plane/domain layer and is correlated down to nodes, containers, cgroups, PIDs, namespaces and kernel evidence where possible.

Security model

LLM output is data, never authority. Autonomous operation is constrained by deterministic policy and execution controls.

Least privilege

The privileged daemon owns sensitive operations. Capabilities declare the access they require.

Policy before execution

Actions are evaluated for principal, target, risk, blast radius, autonomy level, approvals and operational constraints.

Auditability

Plans, policy decisions, actions, executions and evidence form an auditable operational history.

Installation

The product is intended to run as a native Linux/Unix service. Additional package channels are being prepared alongside the source distribution.

Core principles

  • Rust-native core and privileged execution boundary.
  • AI reasoning is separated from privileged authority.
  • Kernel-native evidence is preferred over CLI parsing.
  • Kubernetes is an adapter/control-plane domain, not a prerequisite.
  • Plugins extend capabilities without coupling infrastructure-specific logic to the core.
  • Observed evidence remains distinct from inferred state.

Project status

ARGUS is under active development. Architecture, ADRs, specifications, CI/CD and packaging foundations are being established before the core runtime implementation is completed.
