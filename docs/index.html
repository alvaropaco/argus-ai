What is ARGUS?

Your AI-Powered Infrastructure Companion

ARGUS is a Rust-native autonomous infrastructure operations runtime. It discovers your environment, correlates evidence, reasons about incidents, plans changes, enforces policy, executes permitted actions and validates the outcome.

Linux / Unix / Cloud / K8s

Kernel-native evidence

Prefer first-class Linux kernel interfaces over fragile CLI parsing wherever possible.

Pluggable capabilities

Adapters, agents and plugins extend the runtime without coupling infrastructure-specific logic to the core.

Evidence-backed state

Observed evidence remains distinct from inferred state, hypotheses and AI-generated reasoning.

Security

Autonomy with guardrails

LLM output is treated as data, never authority. Every sensitive operation crosses explicit capability and policy boundaries.

Least privilege

The privileged daemon owns sensitive operations. Capabilities declare the access they require.

Policy before execution

Evaluate principal, target, risk, blast radius, autonomy level, approvals and operational constraints.

Full audit trail

Plans, policy decisions, actions, executions and evidence form an auditable operational history.

Get Started

Install ARGUS

ARGUS ships as two binaries — argus (CLI/TUI) and argusd (privileged daemon) — plus a hardened systemd unit. Linux (x86_64 or aarch64), no Kubernetes/NATS/eBPF required.

1 · Installer script (recommended)

curl -fsSL https://argus.0x-ai.com/install.sh | sudo sh

Downloads the release tarball, verifies its SHA-256 checksum, installs to /usr/bin, and enables + starts argusd. Set ARGUS_NO_START=1 to install without starting.

2 · APT (Debian/Ubuntu)

curl -fsSL https://argus.0x-ai.com/argus-archive-keyring.asc | sudo gpg --dearmor -o /usr/share/keyrings/argus-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/argus-archive-keyring.gpg] https://argus.0x-ai.com stable main" | sudo tee /etc/apt/sources.list.d/argus.list
sudo apt update && sudo apt install -y argus argusd

3 · Cargo (crates.io)

cargo install argus-ai-cli argus-daemon

Installs to ~/.cargo/bin. For the systemd unit, install with --root /usr, or start argusd manually.

4 · From source

git clone https://github.com/alvaropaco/argus-ai.git
cd argus-ai
cargo build --release
# binaries in target/release/{argus,argusd}
Usage

Configure and run

After installing, initialize ARGUS, make sure the daemon is running, and inspect your environment.

1 · Initialize

argus init

Interactive wizard: environment, AI provider, model, and API token. Writes argus.toml plus argus.secrets.toml (mode 0600) — secrets are kept separate.

2 · Start the daemon

systemctl enable --now argusd
# or, without systemd:
argusd

argusd binds /run/argus/argusd.sock and stores state in /var/lib/argus/argus.db.

3 · Query

argus health
argus status
argus capabilities
argus plugins
argus config

4 · Dashboard (TUI)

argus

The TUI connects to argusd; if it reports “connect to argusd”, the daemon isn’t running — start it with step 2.
